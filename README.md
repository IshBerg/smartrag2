# SmartRAG v2

**Version:** 2.0.0
**Date:** 2025-10-26

Гибридная RAG библиотека для Android.

## Архитектура
- SQLite: данные + граф + FTS5
- Rust: векторный поиск (Hora)

## Требования

- Kotlin 2.2.20
