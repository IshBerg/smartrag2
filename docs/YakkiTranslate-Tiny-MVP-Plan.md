## ФАЗА 1: ПОЛУЧЕНИЕ И ПОДГОТОВКА МОДЕЛИ (2 часа)

### Промпт 1.1 - Скачивание модели:

```markdown
Напиши Python скрипт download_model.py который:

1. Скачает Qwen2.5-0.5B-Instruct с Hugging Face:
   - Используй transformers и huggingface_hub
   - Модель: "Qwen/Qwen2.5-0.5B-Instruct"
   - Сохрани в /workspace/models/original/

2. Создай файл model_info.json с метаданными:
   - Размер модели
   - Дата скачивания
   - Версия
   - Поддерживаемые языки

3. Проверь целостность скачанных файлов

Выполни скрипт в песочнице и покажи результат.
```

### Промпт 1.2 - Экспорт в ONNX:

```markdown
Создай скрипт export_to_onnx.py:

1. Загрузи скачанную Qwen модель
2. Экспортируй в ONNX формат с оптимизациями:
   - Квантизация INT8
   - Оптимизация для мобильных
   - Максимальная длина контекста: 512 токенов
3. Сохрани как qwen-0.5b-translator.onnx
4. Создай тестовый inference для проверки

Запусти и проверь, что ONNX модель работает.
```

### Промпт 1.3 - Симуляция MNN конвертера:

```markdown
Так как MNN converter недоступен в песочнице, создай mock версию:

1. Создай скрипт mock_mnn_converter.py который:
   - Читает ONNX модель
   - Создаёт структуру, симулирующую .mnn файл
   - Сохраняет метаданные для Android библиотеки

2. Создай файл mnn_model_spec.json с:
   - Входными/выходными тензорами
   - Размерностями
   - Типами данных
   - Оптимизациями для GPU

Это будет заглушка для разработки, пока не получим реальный MNN.
```

## ФАЗА 2: РАЗРАБОТКА ANDROID БИБЛИОТЕКИ (3 часа)

### Промпт 2.1 - Core JNI интерфейс:

```markdown
В /workspace/yakkitranslate-tiny/library/src/main/cpp/ создай:

1. CMakeLists.txt:
   - Настрой компиляцию для Android
   - Добавь заглушки для MNN библиотек
   - Включи C++14

2. mnn_bridge.cpp:
   - JNI методы для загрузки модели
   - Метод для inference
   - Метод для анализа сложности
   - Обработка ошибок и логирование

3. mock_mnn_runtime.hpp:
   - Заглушка MNN runtime для тестирования
   - Симуляция загрузки модели
   - Простой inference (возврат тестовых данных)

Важно: код должен компилироваться даже без реального MNN.
```

### Промпт 2.2 - Kotlin API:

```markdown
В /workspace/yakkitranslate-tiny/library/src/main/java/com/yakki/translate/ создай:

1. TinyTranslator.kt:
   - Главный класс библиотеки
   - Методы initialize(), translate(), release()
   - Поддержка корутин
   - Обработка ошибок

2. MnnEngine.kt:
   - JNI интерфейс к native коду
   - Загрузка .so библиотек
   - Методы для вызова C++ функций

3. TranslationResult.kt:
   - Data class для результатов
   - Включи: текст, время, сложность, уверенность

4. ModelManager.kt:
   - Загрузка модели из assets
   - Кеширование в internal storage
   - Проверка версий

Каждый файл должен иметь KDoc документацию.
```

### Промпт 2.3 - Токенизатор:

```markdown
Создай простой токенизатор для Qwen в Kotlin:

1. QwenTokenizer.kt:
   - Загрузка словаря из vocab.json
   - Метод encode(text: String): IntArray
   - Метод decode(tokens: IntArray): String
   - Поддержка специальных токенов для перевода

2. resources/vocab.json:
   - Минимальный словарь для тестирования
   - Поддержка русского, английского, иврита
   - Специальные токены: [TRANSLATE], [FROM], [TO]

3. TokenizerTest.kt:
   - Unit тесты для основных языков
   - Проверка round-trip (encode → decode)
```

## ФАЗА 3: ИНТЕГРАЦИЯ И ОПТИМИЗАЦИЯ (2 часа)

### Промпт 3.1 - Orchestrator для маленькой модели:

```markdown
Создай TinyOrchestrator.kt который:

1. Анализирует входной текст и определяет:
   - Сложность (простая фраза / сложное предложение)
   - Язык источника (автоопределение)
   - Наличие специальных символов

2. Выбирает стратегию перевода:
   - Direct: простой однопроходный перевод
   - Refined: двухпроходный с уточнением
   - Chunked: разбивка длинных текстов

3. Оптимизирует для батареи:
   - Кеширование частых переводов
   - Батчинг запросов
   - Умное управление GPU

Добавь метрики производительности.
```

### Промпт 3.2 - Кеширование:

```markdown
Реализуй TranslationCache.kt:

1. LRU кеш для последних 1000 переводов
2. Сохранение в SharedPreferences для persistence
3. Умное сравнение (игнорирование регистра, пробелов)
4. Метрики: hit rate, средняя экономия времени
5. Очистка старых записей (>7 дней)

Интегрируй с TinyTranslator.
```

## ⚠️ ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ MVP:

1. **Mock MNN** - не настоящая производительность
2. **Базовая модель** - без fine-tuning на переводах
3. **Ограниченный словарь** - только базовые слова
4. **CPU-only** - нет GPU ускорения в mock версии
5. **Простой токенизатор** - может пропускать специальные символы

## 💡 СОВЕТЫ ПО ОТЛАДКЕ:

### Если модель не загружается:
- Проверить права доступа к assets
- Убедиться что .so библиотеки скопированы
- Проверить логи JNI

### Если перевод медленный:
- Включить профилирование
- Проверить кеш
- Уменьшить максимальную длину

### Если crash:
- Проверить утечки памяти
- Убедиться в правильной последовательности init/release
- Проверить native logs
